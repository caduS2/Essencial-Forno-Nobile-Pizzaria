# Forno Nobile Pizzaria — Plano Essencial

> **Projeto Modelo / Demonstrativo Comercial da CF Web Studio**  
> Desenvolvido com foco em conversão rápida via WhatsApp, alta performance, design moderno e confiabilidade.

---

## 🍕 Sobre o Projeto

A **Forno Nobile Pizzaria** é uma marca conceitual criada para demonstrar o potencial do **Plano Essencial** da CF Web Studio para micro e pequenas empresas gastronômicas.

O objetivo deste plano é entregar um site institucional ágil, visualmente sofisticado e direto ao ponto:
- **Cardápio Escaneável**: 4 sabores tradicionais com botão de pedido customizado direto para o WhatsApp.
- **Identidade Visual**: Paleta acolhedora com tons de Laranja Queimado (`#EA580C`) e Grafite Escuro (`#121417`), com tipografia nobre (Playfair Display + Raleway).
- **Sem Fricção**: Sem necessidade de cadastros demorados, carrinhos complexos ou integrações de pagamento pesadas — foco 100% no canal de maior conversão brasileira: o WhatsApp.
- **Localização Clara**: Integração com Google Maps, cópia rápida de endereço e aviso de horários.

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/caduS2/Essencial-Forno-Nobile-Pizzaria.git
   cd Essencial-Forno-Nobile-Pizzaria
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Abra no navegador:**
   O projeto estará rodando em `http://localhost:3000` (ou na porta indicada pelo Vite).

---

## 📦 Build de Produção

Para gerar a versão otimizada para deploy (Vercel, Netlify, Cloudflare Pages ou servidor próprio):

```bash
npm run build
```

Os arquivos estáticos estarão prontos na pasta `dist/`.
